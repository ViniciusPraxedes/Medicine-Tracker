# Medicine Tracker

A comprehensive medication tracking application designed to help users manage their prescriptions, track daily doses, and monitor adherence.

## Features

- **Medication Management**: Easily add, edit, and delete medications.
- **Inventory Tracking**: Keep track of pill counts and get reminders when it's time to refill.
- **Dose Logging**: Log daily doses with a simple interface.
- **History & Adherence**: View your medication history and track your adherence over time.
- **Secure Authentication**: Sign in securely using Google Authentication.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **Backend**: Firebase (Firestore, Authentication)
- **Icons**: Lucide React

## Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd medicine-tracker
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure Firebase:**
    - Create a `.env` file in the root directory.
    - Add your Firebase configuration keys (see `.env.example` or ask the administrator).

4.  **Run the application:**
    ```bash
    npm run dev
    ```
